# 🔐 Secret Word

Aplicação interativa desenvolvida com **React**, baseada em um jogo de adivinhação de palavras.  
O objetivo é descobrir a palavra secreta a partir de dicas, testando lógica, vocabulário e raciocínio.

> [!TIP]
> Projeto focado em prática de React, manipulação de estado e criação de lógica de jogo no front-end.

---

## 🚀 Tecnologias utilizadas

- ⚛️ React  
- 🎨 CSS3  
- 🧠 JavaScript (ES6+)  

---

## 💡 Funcionalidades

- 🎮 Sistema de jogo com palavra secreta  
- 🔤 Entrada de letras/palavras pelo usuário  
- ❌ Controle de tentativas  
- ✅ Validação de acertos e erros  
- 🔄 Reinício automático do jogo  
- 📊 Feedback visual em tempo real  
- 📱 Interface simples e responsiva  

---

## 🎯 Objetivo do projeto

Este projeto foi desenvolvido para:

- Praticar conceitos fundamentais do **React**  
- Trabalhar com **useState e lógica de estados**  
- Criar regras de negócio no front-end  
- Simular um jogo completo com interação do usuário
